# إيجاز — استخراج APK مجانًا

تم تجهيز المشروع ليُبنى كـ Android APK باستخدام GitHub Actions، بدون Android Studio وبدون اشتراك مدفوع وبدون مفاتيح توقيع خاصة.

## الطريقة

1. فك ضغط هذا الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد أو إلى المستودع الحالي.
3. تأكد أن الملف موجود بهذا المسار:
   `.github/workflows/build-ejaz-apk.yml`
4. افتح **Actions** في GitHub.
5. اختر **Build Android APK**.
6. اضغط **Run workflow** أو ادفع الملفات إلى `main`/`master`.
7. بعد نجاح البناء، افتح العملية الناجحة وانزل إلى **Artifacts**.
8. نزّل **Ejaz-APK** وفك ضغطه؛ ستجد `Ejaz.apk` جاهزًا للتثبيت على الهاتف.

### ملاحظات

- الـAPK الناتج Debug APK وموقّع بمفتاح Android التجريبي، لذلك يمكن تثبيته مباشرة على الهاتف للاختبار.
- للنشر الرسمي على Google Play لاحقًا، نحتاج إنشاء مفتاح توقيع Release خاص بالتطبيق.
- الـWorkflow يعيد بناء واجهة React ثم ينسخ `dist` إلى Android assets قبل إنشاء APK، لذلك أي تعديل على الواجهة يدخل في التطبيق تلقائيًا.
