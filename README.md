# نظام VICTORIA Logistics ERP — قطاع إيجـاز للنقليات

**VICTORIA Logistics ERP (Enterprise Resource Planning)** — نظام سحابي وتشغيلي متكامل ومترابط لإدارة العمليات اللوجستية، أسطول النقل البري، الشاحنات، السائقين، الرحلات، كشوفات المتابعة، سندات القبض والصرف، المحاضر اليومية، وتطبيق الهواتف الذكية (Android APK) مع المزامنة الحية بين أجهزة الموظفين والإدارة والمالك.

> **ملاحظة الهوية الأساسية**:
> الاسم الرسمي والنهائي للنظام هو **VICTORIA Logistics ERP**، ويشمل داخلياً **قطاع إيجاز للنقليات (EJAZ Transport Module)** لكافة المهام الميدانية والتشغيلية المعتمدة.

---

## 🌟 الهيكلية والمميزات الأساسية:

1. **الخادم المركزي وقاعدة البيانات المركزية**:
   - خادم متكامل مبني بـ Node.js 22 / Express يعمل على المنفذ `3000`.
   - قاعدة بيانات مركزية مدمجة مع حفظ ذري وآمن في `data/ejaz_database.json` ونسخ احتياطي دوري في `data/backups/`.
   - واجهات برمجة تطبيقات (RESTful API) تغطي المستخدمين، الرحلات، السائقين، الشاحنات، الصيانة، المالية، والتدقيق.

2. **المزامنة الحية بين أجهزة الموظفين والإدارة**:
   - مزامنة حية ثنائية الاتجاه (`/api/sync/push` و `/api/sync/pull`) مع معرفات تسلسلية لتفادي التعارضات.
   - دعم كامل للعمل دون اتصال بالإنترنت (Offline-First) وطابور عمليات متزامن (Outbox).
   - تخزين دائم غير محدود عبر IndexedDB و Persistent Storage API لضمان عدم فقدان البيانات بعد إغلاق التطبيق.

3. **الأمان وصلاحيات المستخدمين (RBAC)**:
   - نظام دخول بمصادقة مشفرة عبر `HMAC SHA-256` مع Salt عشوائي لكل مستخدم.
   - حماية العمليات الحساسة على مستوى الخادم والواجهة معاً.
   - أدوار محددة: المالك (المدير العام)، مدير الشركة، مسؤول العمليات، المحاسب المالي، أمين الصندوق، والمدقق.
   - سجل تدقيق مركزي دائم وغير قابل للتعديل يوثق جميع العمليات الميدانية والمالية.

4. **تطبيق Android APK الكامل**:
   - تطبيق Android رسمي مبني بـ WebView مسرّع بالعتاد، معرّف الحزمة الثابت `sa.ejaz.transport`.
   - إصدار `1.1.0` (كود `versionCode: 2`) متوافق مع التثبيت فوق الإصدار السابق مع الحفاظ على البيانات.
   - خط بناء آلي عبر **GitHub Actions** يبدأ من كود نظيف، يجمع حزمة الويب، يتحقق من الحجم، وينتج APK كامل وجاهز.

## 📱 خطوات بناء وتحميل ملف Android APK من GitHub:

1. ادفع أي تعديلات جديدة إلى المستودع الرسمي على الفرع الرئيسي:
   ```bash
   git add .
   git commit -m "تحديث VICTORIA Logistics ERP"
   git push origin main
   ```
2. ادخل إلى صفحة المستودع على **GitHub**.
3. افتح تبويب **Actions**.
4. سير العمل المعتمد: **Build Victoria Logistics ERP APK**.
5. بعد انتهاء عملية البناء بنجاح (علامة صح خضراء):
   - افتح تفاصيل العملية، وانزل لأسفل الصفحة إلى قسم **Artifacts**.
   - حمّل `VICTORIA-Logistics-ERP-APK-v1.1.0`.
   - فك الضغط وثبّت ملف الـ APK على الهاتف.
