# مؤسسة إيجاز للنقليات – Ejaz Logistics ERP (Web, Server & Android APK)

نظام سحابي وتشغيلي متكامل ومترابط لإدارة أسطول النقل البري، الشاحنات، السائقين، الرحلات، سندات القبض والصرف، المحاضر اليومية، والمزامنة الحية بين أجهزة الموظفين والمدير العام والمالك.

---

## 🌟 مميزات وأقسام النظام المترابطة:

1. **الخادم المركزي وقاعدة البيانات المركزية**:
   - محرك خادم Node.js / Express متكامل مدمج يعمل على المنفذ `3000`.
   - قاعدة بيانات مركزية متصلة مع حفظ ذري وكتابة آمنة في `data/ejaz_database.json`.
   - دعم الترحيلات وتكامل العمليات التشغيلية والمالية مع حفظ كامل للبيانات وتحديثها تلقائياً.

2. **المزامنة الحية بين أجهزة الموظفين والإدارة والمالك**:
   - مزامنة سحابية فورية ثنائية الاتجاه (`/api/sync/push` و `/api/sync/pull`).
   - دعم وضع انقطاع الاتصال (Offline-First) مع طابور عمليات محلي (`Outbox`) وبصمات تشفيرية لمنع تكرار البيانات أو تعارضها.
   - مؤشرات لحظية لحالة الاتصال والمزامنة وعدد العمليات المعلقة في شريط الحالة.

3. **الأمان وصلاحيات المستخدمين (RBAC)**:
   - نظام دخول بمصادقة مشفرة عبر خوارزمية `SHA-256` مع ملح تشفيري عشوائي فريد لكل حساب (`Salted Password Hashing`).
   - جلسات آمنة مع رموز مصادقة Bearer Token موقعة بـ HMAC.
   - التحقق من الصلاحيات على مستوى واجهات برمجة التطبيقات (API) والخادم وقاعدة البيانات.
   - أدوار محددة: المالك (المدير العام)، مدير الشركة، مسؤول العمليات، المحاسب المالي، أمين الصندوق، والمدقق.
   - حماية الحسابات الإدارية: لا يمكن لمستخدم عادي تعديل بيانات المالك أو ترقية نفسه.
   - إعداد أول آمن للمالك مع مفتاح استرداد محلي مشفر وميزة فرض تغيير كلمة المرور عند أول دخول للموظفين.

4. **الربط التشغيلي والمالي التام**:
   - ربط إلزامي 1-إلى-1 بين السائق والشاحنة المخصصة لمنع تداخل العهد والرحلات.
   - الرحلات مع توليد الترقيم الآلي، كود الربط التلقائي، والمركز المالي، وحساب الضرائب وصافي الأرباح.
   - سندات القبض والصرف المرتبطة مباشرة بحسابات الرحلات والعملاء ومحاضر التسليم اليومية للمالك.
   - سجل تدقيق مركزي غير قابل للتعديل يوثق كافة العمليات، اسم المستخدم، التاريخ، الوقت، والتفاصيل.

5. **تطبيق Android وتوليد ملف APK**:
   - تطبيق Android أصلي مدمج بـ WebView مسرّع بالعتاد (Hardware Accelerated).
   - بناء آلي فوري عبر GitHub Actions دون الحاجة لبيئة محلية معقدة.
   - خط عمل `.github/workflows/build-ejaz-apk.yml` يقوم ببناء حزمة الويب ونسخها إلى الأصول وإنتاج `app-debug.apk`.

## 🚀 التشغيل والتطوير:

### 1️⃣ التشغيل المحلي (خادم الويب والـ API وقاعدة البيانات):
```bash
# تثبيت الاعتماديات
npm install

# تشغيل الخادم المركزي والتطوير
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2️⃣ بناء حزمة الإنتاج وتحديث أصول Android:
```bash
npm run build
```
سيقوم هذا الأمر ببناء تطبيق React وضغطه وتحديث أصول تطبيق Android في مجلد `app/src/main/assets/www/` تلقائياً.

## 📱 خطوات بناء وتحميل ملف Android APK:

1. ادفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git add .
   git commit -m "تحديث نظام إيجاز وإضافة الخادم المركزي والمزامنة"
   git push origin main
   ```
2. ادخل إلى صفحة المستودع على **GitHub**.
3. افتح تبويب **Actions**.
4. اختر مسار العمل: **Build Victoria Logistics ERP APK**.
5. اضغط **Run workflow**.
6. بعد انتهاء البناء (أقل من دقيقتين)، انزل إلى قسم **Artifacts** وحمّل ملف APK الجاهز للتثبيت على الهواتف فوراً.
